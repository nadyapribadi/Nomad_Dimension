Where keys and billing live

API credentials are configured in Netlify → Project configuration → Environment variables. They stay on the server; this page never displays a key. Changing a key requires a new draft to update that draft's functions.

For Fact-check, the variable is GEMINI_API_KEY. In Google AI Studio, choose the matching project and check Billing → Credit balance. Your spend cap limits usage; it does not add credit.
